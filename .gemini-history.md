# Project History: Basil Editor
## Overview
Basil Editor is a macOS application built with SwiftUI and WKWebView integration. It uses a locally bundled Tiptap editor (built with Vite) as its primary rich-text editor, bridging Swift and JavaScript for content management.

## Core Architectural Principles
- **Frameworks**: SwiftUI (UI), WebKit (Editor Bridge), Tiptap (Rich Text), Vite (Build Tool).
- **Architecture**: Local Asset WebView-Bridge. The editor is built from the `web-editor/` sub-project and bundled into the app's resources (`Basil/WebEditor`).
- **Data Flow**: Two-way binding between SwiftUI `@Binding` and Tiptap via `WKScriptMessageHandler` and `evaluateJavaScript`.
- **Styling**: Modern macOS aesthetics. The editor is hosted in a transparent WebView, inheriting system colors while using custom CSS for typography.
- **Persistent Memory**: Active. All session updates are logged here.
